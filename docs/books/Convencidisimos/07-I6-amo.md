# I.6 — «Yo amo a Dios»

**Texto:** 1 Juan 4:20-21  
**Puerta:** 4:19 — está **antes** de la acusación. La respuesta ya estaba en el cuarto cuando se presentó el cargo.  

El Dios invisible es el socio perfecto del autoengaño: se deja guionar y nunca contradice. El hermano visible contesta. Por eso la carta lo usa de instrumento.
