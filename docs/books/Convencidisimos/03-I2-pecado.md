# I.2 — «No tenemos pecado»

**Texto:** 1 Juan 1:8, 1:10  
**Puerta:** 1:9 y 2:1-2 — *él es fiel*; hay Abogado. La respuesta es el versículo siguiente.  

Las dos negaciones, más la máquina expendedora: 1:9 leído como procedimiento. La rejilla que alterna. *El pecado no apaga la luz; la versión, sí.*
