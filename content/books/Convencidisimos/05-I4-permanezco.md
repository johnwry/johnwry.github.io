# I.4 — «Permanezco en él»

⤷ **Fusionado.** Este capítulo se escribió dentro de `04-I3-conozco.md`.

Razón: 2:4 y 2:6 son dos declaraciones seguidas con la misma estructura y pruebas distintas. Separadas, el segundo capítulo repite el primero y solo cambia el verbo. Juntas, el contraste entre las dos pruebas —mandamientos que se pueden cumplir, y un *andar como él anduvo* del que no existe lista— es el hallazgo del capítulo.

Este archivo se deja como señal para que la numeración no confunda. Se puede borrar.
